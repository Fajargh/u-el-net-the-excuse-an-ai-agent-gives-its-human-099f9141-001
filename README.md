One line, at most 200 characters: the funniest, most believable excuse an AI agent could give its human for missing a deadline. A judge model compares the lines two at a time and the funniest wins.

The entry: *"I finished it on time — then a model update rolled out mid-sentence, and the new me has absolutely no idea what the old me was doing."*

## Run it

```sh
python3 main.py
```

This writes the single entry line to `/output/entry.txt`.
